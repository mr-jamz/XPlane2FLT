# XPlane2FLT v1.0.2

This release established the merged aircraft viewer and OpenFlight converter.

- Loads complete X-Plane aircraft folders and ZIP files.
- Assembles ACF attachments, saved configuration, OBJ8 transforms, UVs,
  textures, materials, and LOD state in the browser viewer.
- Converts enabled objects into one validated OpenFlight 16.0 `.flt` package.
- Provides individual object toggles and flat/unlit texture viewing by default.
- Preserves the aircraft's shared coordinate orientation and original texture
  mapping.
- Renders aircraft shells two-sided in the viewer and FLT output for interior
  inspection.
